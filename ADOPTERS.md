# Adopters

An adopter is anyone who runs `k8s-status` against a cluster they care about, at work or
at home. There are no listed adopters yet.

If you run it and want to be listed, open a pull request that adds a row to the table
below. A row is one line:

- **who**, an organisation or team name, or a description such as "a platform team at a
  bank" when the name cannot be published,
- **contact**, a GitHub handle or other address you do not mind making public, so the
  claim has someone behind it,
- **link**, optional, a public page about the team or how it uses the project,
- **notes**, what the page is used for, and whether the deployment follows ArgoCD, Flux,
  or both.

Keep the table alphabetical by organisation.
