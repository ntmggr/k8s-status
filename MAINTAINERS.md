A maintainer reviews and merges pull requests, cuts releases, holds the publishing
credentials, and answers security reports. What the role involves and how someone
becomes one is described in [GOVERNANCE.md](GOVERNANCE.md). This file is only the list,
so that the question "who maintains this?" has one place to look.

Neither public GitHub profile publishes a name, so each handle stands in for one until
its owner says what belongs in the Name column.

The Company column is a fact about employment, so it changes when a maintainer changes
jobs, and this table should change with it.

## Emeritus

None yet. A maintainer who steps back moves to a section here rather than disappearing
from the file, so the project's history stays readable.
